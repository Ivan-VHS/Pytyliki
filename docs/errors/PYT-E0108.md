# PYT-E0108 — WAV input cannot be read

**Severity:** error · **Status:** active

The selected file is not a supported PCM WAV stream, or its declared chunk sizes and actual file contents do not agree.

**Typical causes**
- A truncated or partially copied file.
- An unsupported encoding or malformed RIFF/WAVE header.
- A chunk size that extends beyond the end of the file.

**How to fix it**

Re-export the source as a complete PCM16 WAV. Run `pytyliki --audio-info FILE.wav` first, then retry the processing command. Keep the original file unchanged until the replacement has been checked.
