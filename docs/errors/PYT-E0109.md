# PYT-E0109 — Audio processing parameter is not finite

**Severity:** error · **Status:** active

A DSP numeric parameter must be finite. NaN and positive or negative infinity are rejected rather than passed into the audio pipeline.

**Typical causes**
- A literal such as `nan` or `inf` was supplied.
- A conversion overflowed before the DSP stage.
- A value was copied from a diagnostic or configuration field that is not a numeric setting.

**How to fix it**

Supply a finite number within the range documented for the selected option. Use an ordinary numeric value instead of NaN or infinity.
