# Unified Documentation and Semantics Standard

**Canonical specification:** [DAK — Unified Documentation and Semantics Standard](https://github.com/Ivan-VHS/DAK/blob/main/docs/UNIFIED_DOCUMENTATION_STANDARD.md).

Use the shared vocabulary for implementation maturity, runtime state, verification outcome, integration policy and evidence. Pytyliki source, tests, C ABI declarations, schemas and CMake files remain authoritative for local behavior.

The shared policy includes the 50-point README publication checklist covering identity and metadata, release provenance, architecture and contracts, breaking changes and limitations, performance evidence, localization, navigation, legal attribution and clean-environment verification. See [Documentation Control](DOCUMENTATION_CONTROL.md) for Pytyliki-specific review gates.
