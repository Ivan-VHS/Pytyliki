# Embedded C workbench

| Tool | Result |
|---|---|
| MCU profile | reference CPU/ISA and memory map |
| Memory budget | FLASH/SRAM usage and remaining capacity |
| MMIO model | masked register simulation |
| Starter generator | project skeleton and build hints |

Profiles are reference data; MMIO is simulated. No physical register, firmware, bootloader or device is written.
