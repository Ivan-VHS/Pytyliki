# Improvement and conflict resolution

`improvement-conflict.v1.json` retains the canonical 20 × 3 vocabulary and evidence states.

| Step | Rule |
|---:|---|
| 1 | detect reproducible symptoms |
| 2 | confirm the root cause |
| 3 | propose bounded change + rollback |
| 4 | implement on a branch |
| 5 | test, review and document |
| 6 | merge only after required checks and human approval |

A conflict label is a diagnostic category, not proof that a defect exists.
